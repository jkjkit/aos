# FAQ Generation

从历史数据自动**挖掘高频问题**并**生成结构化 FAQ**。**不**直接回复客户（那是 `cs-response`），**不**工单分类（那是 `support-triage`）。

## 何时使用

- 新建客服知识库
- 客服每周高频问题应沉淀为 FAQ
- 产品文档不直观，想转成问答形式
- 想减少重复工单

不要用于：

- 单次回复客户 → `cs-response`
- 工单分类 → `support-triage`
- 流失挽回 → `customer-recovery`

## 流程

### 1. 收集数据源

可挖掘的数据：

| 数据源 | 适合挖掘什么 |
|--------|-------------|
| 历史工单 | 高频问题、常见误解 |
| 客服聊天记录 | 真实用户问法 |
| 产品文档 | 功能说明、操作步骤 |
| 会议纪要 | 内部讨论的常见疑问 |
| 社区 / 论坛 | 用户主动问的问题 |
| 销售对话 | 售前常见疑问 |

### 2. 聚类问题

把所有问题聚类：

```
数据：1000 条工单
  ↓ 去重 / 标准化
800 个独立问题
  ↓ 关键词聚类
  - 「怎么重置密码」→ 23 条 → 1 个 FAQ
  - 「数据导出」→ 18 条 → 1 个 FAQ
  - 「退款」→ 35 条 → 1 个 FAQ
  ↓
20 个高频 FAQ 候选
```

聚类方法：

- **关键词提取**：从问题中提取核心名词 + 动词
- **相似度匹配**：向量搜索 / 编辑距离
- **人工 review**：低频长尾问题暂不进 FAQ

### 3. 筛选入 FAQ

筛选标准：

| 维度 | 标准 |
|------|------|
| 频次 | 月 ≥ 10 次 |
| 影响 | 影响 ≥ 80% 用户 |
| 时效 | 答案不会快速过期 |
| 可解 | 客服能给出明确答案 |
| 价值 | 自动化能节省时间 |

不入选：

- 个案（一次性问题）
- 需要专业判断（不是 FAQ 能解决的）
- 答案涉及具体客户数据

### 4. 写 FAQ

每个 FAQ 的标准结构：

```markdown
## 问题：[用户原话]

**适用场景：**
- 用户类型：所有人 / 新用户 / 老用户
- 触发时机：注册时 / 使用某功能时 / 付费时

**解答：**

[1. 直接答案]
[2. 步骤说明]
[3. 示例]

**常见误区：**
- ❌ [错误理解]
- ✅ [正确理解]

**相关问题：**
- [链接到其他 FAQ]

**更新时间：** YYYY-MM-DD
**负责人：** [团队 / 个人]
```

### 5. 持续更新

```
每周：高频问题 → 候选 FAQ
每月：审核 + 发布
每季：清理过期 FAQ
每次产品改动：更新相关 FAQ
```

## 输出格式

```markdown
# FAQ: <主题 / 产品>

## 数据来源
- [来源 1]
- [来源 2]

## 聚类结果
- 高频问题：N 个
- 中频问题：M 个
- 长尾问题：K 个

## 入库 FAQ

### FAQ-001: <问题>
[标准结构]

### FAQ-002: <问题>
[标准结构]

## 候选 FAQ（待评估）
- [候选 1]
- [候选 2]

## 维护计划
- 每周 review 工单
- 每月发布更新
- 季度清理
```

## Hard Rules

### 禁止：照搬产品文档

```
❌ 复制文档章节当 FAQ
✅ 重新组织成「问题 - 答案」形式
```

### 禁止：答案含糊

```
❌ 「请查看相关文档」
✅ 具体步骤 + 链接
```

### 禁止：长期不更新

```
❌ 上线后再没维护
✅ 每次产品改动同步更新
```

### 禁止：答案不一致

```
❌ FAQ 说 A，工单回复说 B
✅ FAQ 是单一事实源，工单按 FAQ 答
```

## 行为准则

- **用户视角**：FAQ 是用户原话，不是内部术语
- **可执行**：答案具体到步骤，不要含糊
- **可发现**：FAQ 应该有清晰分类和搜索
- **可维护**：每条 FAQ 有负责人和更新时间
- **可度量**：定期看 FAQ 覆盖率（多少工单能靠 FAQ 自助）

## 与其它 Skill 的协作

| Skill | 关系 |
|---|---|
| `support-triage` | 上游：工单分类系统应优先推 FAQ |
| `cs-response` | 下游：客服用 FAQ 回答 |
| `summary` | 上游：挖掘工单需要先提炼 |
| `document` | 并行：FAQ 也是文档 |
