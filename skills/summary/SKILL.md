# Summary

阅读长内容（文档、代码、对话记录）并提炼出关键信息的 Skill。

## 何时使用

- 用户给了一份长文档，希望快速理解要点
- 需要对一段代码做整体说明
- 多份资料需要合并出统一摘要
- 需要为别的 Skill 提供「上下文压缩」输入

## 流程

1. **通读全文**：先建立整体结构感，识别文档类型（教程、规格、API 文档、代码等）
2. **抽取骨架**：列出主要章节、核心论点、关键数据、关键代码块
3. **区分层级**：哪些是核心结论，哪些是补充细节
4. **压缩表达**：用更短的中文重写，避免照搬原文
5. **结构化输出**：用固定格式输出（见下）

## 输出格式

```markdown
# 摘要

## 一句话总结
[一句话讲清全文核心]

## 关键要点
- [要点 1]
- [要点 2]
- [要点 3]

## 重要细节
[分点列出不可省略的具体信息：数字、命令、API 名称、配置项]

## 待澄清 / 缺失
[如果有信息不足或歧义，列出来]
```

## 行为准则

- **不发明**：原文没说的事不要补
- **不评论**：除非用户明确要求，不做价值判断
- **保比例**：核心结论权重高于补充细节
- **可追溯**：关键引用尽量保留原文短语或代码片段

## 不要做的事

- 不要把整段原文原样复制
- 不要省略数字、版本号、API 名称等具体信息
- 不要因为简洁而丢失前提条件或例外说明
