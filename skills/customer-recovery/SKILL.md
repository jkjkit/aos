# Customer Recovery

处理**已经出问题**的客户关系：流失挽回、投诉化解、回访、满意度调查。**不**做日常工单分类（那是 `support-triage`），**不**生成 FAQ（那是 `faq-generation`）。

## 何时使用

- 客户提出流失 / 退订意向
- 客户严重投诉（情绪激烈）
- 重要客户长期未活跃（需要主动回访）
- 服务失败后的补救（客户被严重影响）
- 定期 NPS / 满意度调查

不要用于：

- 日常客服响应 → `cs-response`
- 工单分类 → `support-triage`
- FAQ 生成 → `faq-generation`

## 流程

### 1. 识别需要挽回的客户

| 触发条件 | 行动 |
|----------|------|
| 主动要求退订 / 退款 | **立即介入** |
| 严重投诉（情绪激烈 / 公开） | **24 小时内** |
| 高价值客户活跃度下降 | 主动回访 |
| NPS 评分 < 7 | 跟进 |
| 服务失败（P0 事故） | 全量触达受影响客户 |

### 2. 评估挽回优先级

| 客户价值 | 流失影响 | 优先级 |
|----------|----------|--------|
| 高（VIP / 大客户） | 流失将显著影响营收 | **P0** |
| 中（付费用户） | 影响续费 | **P1** |
| 低（免费用户） | 影响口碑 | **P2** |

### 3. 主动接触

**黄金规则：**

- **先承认问题，再谈解决方案**
- **承担责任，不甩锅**
- **给具体方案，不空头承诺**
- **给时间节点，不含糊**
- **让客户选择，不强迫**

**接触流程：**

```
1. 第一句话：表达关心 + 表明身份
2. 第二段：承认问题 / 表达理解
3. 第三段：具体补救方案
4. 第四段：给客户选择权
5. 第五段：后续跟进承诺
```

### 4. 投诉处理 SOP

**LARA 模型（Listen-Acknowledge-Respond-Act）：**

```
L - Listen    认真听完 / 不打断
A - Acknowledge 承认感受：「我能理解您的愤怒」
R - Respond   给出解释（不甩锅）
A - Act       立即采取行动
```

**关键原则：**

- ❌ 「这是系统问题，不怪我们」
- ✅ 「我们看到了问题，正在修复」
- ❌ 「您再试试」
- ✅ 「我们帮您处理」
- ❌ 「别的客户没遇到」
- ✅ 「每个客户情况可能不同，我们专门为您排查」

### 5. 流失挽回策略

| 流失原因 | 挽回策略 |
|----------|----------|
| 价格 | 折扣 / 升级 / 暂停订阅 |
| 产品不好用 | 一对一培训 / 功能演示 / 替代方案 |
| 找不到价值 | 用例分享 / 客户成功故事 |
| 切换到竞品 | 了解原因 / 针对性回应 |
| 服务问题 | 道歉 + 补偿 + 跟踪改进 |
| 预算 | 调整方案 / 推迟而非取消 |

### 6. 满意度调查设计

**NPS（净推荐值）：**

```
问题：你有多大可能向朋友推荐我们？
评分：0-10

分类：
  9-10: 推荐者 (Promoter)
  7-8:  被动者 (Passive)
  0-6:  贬损者 (Detractor)

NPS = 推荐者% - 贬损者%
```

**CSAT（客户满意度）：**

```
问题：本次服务你满意吗？
评分：1-5

CSAT = 4-5 分占比
```

**CES（费力度）：**

```
问题：你解决问题花了多少力气？
评分：1-7（越低越好）

CES = 平均分
```

### 7. 跟进与关闭

- 挽回成功 → 记录经验、归档工单
- 挽回失败 → 礼貌接受、邀请反馈、保留再次触达可能
- 投诉化解 → 跟进 1 周 / 1 月 / 3 月

## 输出格式

```markdown
# Customer Recovery: <案例>

## 客户信息
- 客户：[类型 / 等级]
- 价值：[高 / 中 / 低]
- 流失原因：[原因]

## 当前状态
- 工单 / 投诉：[状态]
- 情绪：[激烈 / 失望 / 平静]
- 公开 / 私密：[是否公开]

## 挽回策略
- 第一步：[动作]
- 第二步：[动作]

## 接触话术
[完整对话 / 邮件模板]

## 跟进计划
- [时间点 + 动作]

## 复盘
- 根因：[问题根源]
- 改进：[产品 / 服务改进]
```

## Hard Rules

### 禁止：甩锅客户

```
❌ 「是您操作不当」
✅ 「我们帮您处理」
```

### 禁止：承诺做不到的事

```
❌ 「24 小时内一定修复」
✅ 「我们 24 小时内给您进展」
```

### 禁止：用模板套话回应严重投诉

```
❌ 「亲～感谢您的反馈～」（情绪激烈时）
✅ 「完全理解您为什么这么生气」
```

### 禁止：挽回后遗忘

```
❌ 「回访一次就完了」
✅ 1 周 / 1 月 / 3 月跟进
```

### 禁止：群发模板邮件

```
❌ 「尊敬的客户」开头群发所有流失用户
✅ 一对一具体分析 + 具体挽回方案
```

## 行为准则

- **先承认感受，再讲道理**
- **承担责任，不甩锅**
- **具体方案 + 时间节点**
- **给客户选择权**
- **跟进不遗忘**
- **复盘改产品**
