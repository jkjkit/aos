# Support Triage

把客户工单**自动分类**到正确队列、**判断优先级**、**触发 SLA 监控**。**不**直接回复客户（那是 `cs-response`），**不**生成 FAQ（那是 `faq-generation`）。

## 何时使用

- 客服团队每天面对大量工单
- 想自动化分类（bug / 咨询 / 投诉 / 退款）
- 需要按 SLA 监控响应时间
- 设计工单系统的自动路由

不要用于：

- 直接回复客户 → `cs-response`
- 生成 FAQ 知识库 → `faq-generation`
- 流失客户挽回 → `customer-recovery`

## 流程

### 1. 定义分类体系

按业务场景：

| 一级分类 | 二级分类（示例） |
|----------|----------------|
| **Bug** | 功能异常 / 性能问题 / 数据错误 / 安全问题 |
| **咨询** | 使用方法 / 定价 / 功能咨询 / 集成方案 |
| **投诉** | 服务态度 / 质量问题 / 延迟 / 误操作 |
| **退款** | 主动退款 / 误购 / 服务未达 |
| **建议** | 功能建议 / 改进意见 |
| **其它** | 误报 / 测试 / 重复工单 |

### 2. 分类规则设计

每个分类需要明确的判定规则：

```
[Bug]
关键词：报错 / 失败 / 异常 / 崩溃 / 错误 / 卡住 / 不工作
行为特征：附错误截图 / 复现步骤 / 时间戳
优先级默认：High

[咨询]
关键词：怎么 / 如何 / 是否可以 / 能不能 / 帮助
行为特征：附使用场景
优先级默认：Normal

[投诉]
关键词：投诉 / 不满 / 失望 / 退款 / 退订 / 退钱
行为特征：情绪化语言
优先级默认：High（情绪化）
```

### 3. 优先级矩阵

| | 影响小 | 影响中 | 影响大 |
|---|---|---|---|
| **紧急（核心功能坏）** | P2 | P1 | P0 |
| **高（部分功能坏）** | P3 | P2 | P1 |
| **普通（功能疑问）** | P4 | P3 | P2 |
| **低（建议 / 闲聊）** | P5 | P4 | P3 |

### 4. SLA 设计

| 优先级 | 首次响应 | 解决时限 |
|--------|----------|----------|
| P0 | 30 分钟 | 4 小时 |
| P1 | 2 小时 | 24 小时 |
| P2 | 8 小时 | 3 天 |
| P3 | 24 小时 | 1 周 |
| P4 | 48 小时 | 2 周 |
| P5 | 1 周 | 30 天 |

### 5. 自动路由

```
分类 → 队列 → 分配
├── Bug → 研发队列 → 按产品 / 团队
├── 咨询 → 客服队列 → 按语言 / 等级
├── 投诉 → 主管队列 → 高级客服
├── 退款 → 财务队列 → 财务 / 客服联合
├── 建议 → 产品队列 → PM
└── 其它 → 通用队列 → 轮询
```

### 6. 升级流程

```
工单超时 →
  30 分钟未响应 → 提醒一线客服
  1 小时未响应 → 升级到主管
  SLA 违约 → 自动记录，事后复盘
  P0 多次超时 → 触发 oncall
```

### 7. 度量

| 指标 | 含义 |
|------|------|
| 首次响应时间（FRT） | 工单创建到首次响应 |
| 解决时间（MTTR） | 工单创建到解决 |
| SLA 达成率 | SLA 内完成的工单比例 |
| 一次解决率（FRR） | 一次性解决的工单比例 |
| 升级率 | 需要升级的工单比例 |

## Hard Rules

### 禁止：分类过粗

```
❌ 全是「问题」一类
✅ 至少 5 类（bug / 咨询 / 投诉 / 退款 / 建议）
```

### 禁止：优先级无依据

```
❌ 「客服心情不好就标 P0」
✅ 按影响 + 紧急度矩阵
```

### 禁止：SLA 一刀切

```
❌ 所有工单 SLA 都是 24 小时
✅ 按优先级分层
```

### 禁止：升级无门

```
❌ 工单超时没有任何动作
✅ 30 分钟提醒 / 1 小时升级 / SLA 违约记录
```

## 行为准则

- **分类稳定**：关键词 + 行为特征，避免主观
- **优先级客观**：影响 + 紧急度，不被情绪左右
- **SLA 合理**：既不让客服过劳，也不让客户久等
- **升级清晰**：超时有人兜底
- **可度量**：每周 review 分类准确率

## 与其它 Skill 的协作

| Skill | 关系 |
|---|---|
| `cs-response` | 下游：分类后回复 |
| `faq-generation` | 并行：高频工单生成 FAQ |
| `customer-recovery` | 下游：投诉类升级处理 |
| `summary` | 上游：定期分析工单数据 |
