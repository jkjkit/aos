# Name


Coding Style Guide


---


# Purpose


定义编码规范，确保代码风格统一、可读性好、易于维护。


---


# Scope


适用于：


- 所有项目代码

- 所有编程语言（有语言特定扩展）
- 所有团队成员

不适用于：


- 第三方库代码

- 自动生成的代码
- 临时测试代码
- 原型验证代码

---


# Content Type


类型：规范（Convention）


包含：


- 命名规范

- 格式规范
- 注释规范
- 最佳实践
- 反模式警告

---


# Update Frequency


更新频率：按需更新


触发条件：


- 团队共识变化

- 新技术引入
- 发现规范缺陷
- 行业标准更新

审核周期：每季度 Review


---


# Usage


## 使用时机


- 编写新代码前

- Code Review 时
- 技术决策时
- 新成员入职时

## 使用方式


- 作为参考指南

- 作为 Review 标准
- 作为培训材料

## 不使用


Knowledge 不参与：


- 自动执行

- 推理决策
- Workflow 触发

---


# Maintenance


## 维护者


技术负责人


## 更新流程


1. 提出修改建议

2. 团队讨论
3. 达成共识
4. 更新内容
5. 通知团队

## 版本管理


遵循语义化版本：


- Major: 重大变更

- Minor: 新增内容
- Patch: 修正错误
